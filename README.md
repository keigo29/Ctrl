# PadRemote

スマホ（PWA）から **Bluetooth (BLE)** で Redmi Pad 2 や Mac を操作するリモコン。
つないだ相手が Redmi Pad か Mac かを自動で判別し、ボタン表示が切り替わります。

- トラックパッド（カーソル移動・タップ・長押し・2本指スクロール・ドラッグ）
- 文字入力（日本語OK。スマホで打った文字をタブレットの入力欄に送信）
- 戻る / ホーム / 履歴 / 通知 / クイック設定 / 画面ロック
- **ランチャー**：よく使うアプリやサイトをボタン1つで起動（Stream Deck風。Redmi Pad用・Mac用で別々に保存）

## しくみ

```
スマホ（PWA / Web Bluetooth）──BLE書き込み──▶ タブレット（PadRemoteアプリ）
                                              ├ BLE GATTサーバーで受信
                                              └ ユーザー補助サービスで
                                                カーソル表示・タップ・文字入力・ボタン操作
```

PWAはタブレットに「Bluetoothマウス」として直接つなぐことができない（Web Bluetoothは接続しに行く側にしかなれない）ため、タブレット側に受信アプリを入れる構成にしています。

## フォルダ

| パス | 内容 |
|---|---|
| `android/` | タブレット用の受信アプリ（Java・ライブラリ依存なし・minSdk 30） |
| `mac/` | Mac用の受信アプリ（Swift・メニューバー常駐） |
| `pwa/` | スマホ用のリモコンPWA（index.html 1枚） |
| `.github/workflows/` | APKビルド・Macアプリビルド・GitHub Pages公開 |

## セットアップ

### 1. GitHubに置く
1. 新しいリポジトリ（例：`keigo29/PadRemote`）を作り、このフォルダの中身をpush
2. リポジトリの **Settings → Pages → Source** を「**GitHub Actions**」にする
3. Actionsが2つ走る
   - **Build APK** → 完了画面の Artifacts から `PadRemote-apk` をダウンロード
   - **Deploy PWA** → `https://<ユーザー名>.github.io/PadRemote/` で公開（Web BluetoothはHTTPS必須）

### 2. タブレット（Redmi Pad 2）
1. APKをインストール（提供元不明のアプリを許可）
2. PadRemoteを開き「① Bluetoothの権限を許可」
3. 「② ユーザー補助」→ ダウンロードしたアプリ → PadRemote をオン
   - グレーアウトしてオンにできない場合：アプリ情報 → 右上︙ →「**制限付き設定を許可**」してからもう一度
4. HyperOS対策（止められないように）
   - アプリ情報 → **自動起動をオン**
   - バッテリーセーバー → **制限なし**
   - アプリ情報 → その他の権限 → **バックグラウンドでのポップアップウィンドウの表示を許可**（ランチャーでアプリを開くのに必要）
5. アプリの状態が「待機中（スマホから接続できます）」になればOK

### 2b. Mac
1. ターミナルで `bash mac/build.sh`（初回は `xcode-select --install` が必要）
   - または GitHub Actions の **Build Mac app** の Artifacts から `PadRemote-mac` をダウンロード
     （ダウンロードしたものは開けないことがあるので `xattr -dr com.apple.quarantine PadRemote.app` を実行）
2. `PadRemote.app` を「アプリケーション」に入れて起動 → メニューバーにアイコンが出る
3. 初回だけ許可する
   - **Bluetooth**：起動時のダイアログで許可
   - **アクセシビリティ**：システム設定 → プライバシーとセキュリティ → アクセシビリティ → PadRemote をオン
4. メニューの「状態」が「待機中」になればOK
5. ビルドし直すと許可が外れることがあります。その場合はアクセシビリティの一覧から一度削除して、もう一度オンにする

メニューバーから切り替えられる設定
- **カーソルのハイライトを表示**：操作中だけカーソルの周りに丸を表示
- **文字はペーストで入力**：オンだと日本語入力モードのままでも確実に入る（クリップボードは0.5秒後に元に戻す）

### 3. スマホ
- **Android**：ChromeでPagesのURLを開く → 「接続」→ 一覧から Redmi Pad または Mac を選ぶ → ホーム画面に追加
- **iPhone**：SafariはWeb Bluetooth非対応なので、App Storeの「**WebBLE（ioswebble）**」を入れ、
  設定 → アプリ → Safari → 機能拡張 で有効化（すべてのWebサイトで許可）→ SafariでURLを開いて「接続」
  - ホーム画面から開いた版で拡張が効かない場合は Safari のタブで使う

## 操作

| 操作 | 動作 |
|---|---|
| 1本指でなぞる | カーソル移動（速く動かすほど加速） |
| タップ | クリック |
| 1本指で長押し / 2本指タップ | 長押し |
| 2本指でスライド | スクロール |
| 「ドラッグ」→ カーソル移動 →「ここで離す」 | 長押しドラッグ（アイコン移動・範囲選択） |
| 文字を入れて「送信」/ キーボードの送信 | フォーカス中の入力欄に挿入 |

右端の「スクロール」帯を1本指でなぞってもスクロールできます。
カーソルは8秒操作しないと消えます。

### ランチャー

トラックパッドの上の切り替えで「ランチャー」を選ぶと、登録したボタンが並びます。

- タップ：そのアプリ・サイトを起動
- 「編集」をオン → ボタンをタップで編集（名前・アプリ名/URL・アイコン・色・並び順・削除）
- 「＋ 追加」でボタンを増やす

| 種類 | Redmi Pad | Mac |
|---|---|---|
| アプリ | ホーム画面の表示名（`YouTube`・`マップ`）またはパッケージ名 | 英語のアプリ名（`Safari`・`Notes`）またはバンドルID |
| サイト | ブラウザ（対応アプリがあればアプリ）で開く | 既定のブラウザで開く |

ボタンの設定はスマホ（ブラウザ）に保存されます。

### Macにつないだとき

| ボタン | Macでの動作 |
|---|---|
| 戻る | ⌘[ |
| デスクトップ | デスクトップを表示 |
| 一覧 | Mission Control |
| 検索 | Spotlight（⌘Space） |
| アプリ切替 | 直前のアプリへ（⌘Tab） |
| ロック | 画面ロック（⌃⌘Q） |
| 長押し / 2本指タップ | 右クリック |
| 素早く2回タップ | ダブルクリック |
| ドラッグ | 本物のドラッグ（押したまま移動して離す） |
| 文字送信 | カーソルのある場所に入力（入力欄の選択は不要） |感度は画面下の「感度の設定」で変更できます。

## 通信プロトコル（BLE）

- Service `7a1c0001-5d2b-4c6e-9f0a-3b8e2d4c6a10`
- Characteristic `7a1c0002-5d2b-4c6e-9f0a-3b8e2d4c6a10`（Write / Write Without Response）：操作コマンド
- Characteristic `7a1c0003-5d2b-4c6e-9f0a-3b8e2d4c6a10`（Read）：接続先の種類（`android` / `mac`）

| 1バイト目 | 内容 | 続くデータ |
|---|---|---|
| 0x01 | カーソル移動 | int16 dx, int16 dy（リトルエンディアン） |
| 0x02 | タップ | |
| 0x03 | 長押し | |
| 0x04 | スクロール | int16 dx, int16 dy |
| 0x05 | システム操作 | uint8（1戻る 2ホーム 3履歴 4通知 5クイック設定 8ロック 9スクショ） |
| 0x06 | 文字（分割） | UTF-8 最大19バイト |
| 0x07 | 文字確定（挿入） | |
| 0x08 | 1文字削除 | |
| 0x09 | Enter | |
| 0x0A / 0x0B | ドラッグ開始 / 終了 | |
| 0x0C | カーソルを中央へ | |
| 0x0D | 起動（0x06で送った文字列を使う） | `app:名前` または `url:URL` |

## 制限

- 文字入力はユーザー補助の「テキスト設定」を使うので、ゲームや一部の独自入力欄では入らないことがあります
- 動画アプリのDRM画面など、システムがジェスチャー注入を拒否する画面があります
